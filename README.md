# Mockito Workshop — Unit-тесты на Java

Учебный проект, демонстрирующий написание unit-тестов с помощью **JUnit 5** и **Mockito**. В проекте три сервиса — работа с клиентами, заказами и складами — и набор тестов, покрывающих обычные, граничные сценарии и обработку ошибок. Все зависимости (репозитории и смежные сервисы) подменяются моками, чтобы тесты были изолированными и быстрыми.

## Стек

- Java 21+
- Maven
- JUnit 5 (Jupiter)
- Mockito 5.21.0
- Byte Buddy 1.17.7 (для совместимости с Java 25)

## Что внутри

**CustomerServiceTest** — 3 теста: получение существующего клиента «Ivan», создание нового «Oleg», обработка пустого имени. Проверяются порядок и точное количество вызовов репозитория через `InOrder`, а также аргументы через `ArgumentCaptor`.

**OrderServiceTest** — тесты создания заказа, добавления товара с достаточным запасом, обработки `ProductNotFoundException`, быстрой доставки, а также симуляции ошибок через `thenThrow` и работы со `spy`. Есть параметризованный тест с `@ValueSource`.

**WarehouseServiceTest** — 10 тестов: поиск склада с товаром, выбор ближайшего склада среди нескольких, граничные случаи (нулевое и отрицательное количество) и проверка отсутствия товара. Используются `spy` с `doReturn` и `InOrder`.

## Применённые приёмы Mockito

`@Mock`, `@InjectMocks`, stubs (`when...thenReturn`), `doReturn(...).when(spy)`, `verify`, `times`, `verifyNoMoreInteractions`, `InOrder`, `ArgumentCaptor`, `thenThrow`, `spy`, `@ParameterizedTest` с `@ValueSource`.
